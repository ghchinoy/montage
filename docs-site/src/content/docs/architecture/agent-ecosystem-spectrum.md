title: The Agent Ecosystem Spectrum
description: "The 4-tier spectrum of agent tooling: Pure Skills, Skills with Code, Clustered MCP Servers, and Agent Plugins."
---

Montage generates tooling across four tiers of the agent artifact spectrum:

### 1. 📝 Pure Skills
Domain rules, review procedures, and authored sub-agent personas requiring **zero runtime dependencies**. Ideal for advisory checklists, architectural patterns, and code review standards.

### 2. ⚡ Skills with Code
Workflow instructions paired with deterministic scripts to filter raw data and reduce LLM token usage by **60–90%**.

### 3. 🔌 Clustered MCP Servers
Model Context Protocol servers with tools organized by operational personas rather than sprawling flat lists.

### 4. 🧩 Agent Plugins
Turn-key packages adhering to the [Agent Plugins Specification](https://agent-plugins.org) (`plugin.json`, `mcp.json`, and specialized `skills/`).
