<CardGrid stagger>
  <Card title="5-Dimension Readiness Scorecard" icon="pencil">

  </Card>
  <Card title="Multi-Tier Tooling Scaffolder" icon="puzzle">

  </Card>
  <Card title="Fine-Grained Capability Discovery" icon="magnifier">

## The Readiness Spectrum

Montage classifies every application into one of five operational readiness tiers:

| Tier | Name | Readiness Profile | Recommended Agent Artifact |
|:---:|---|---|---|
| **Tier 5** | **Agent-Native** | Non-interactive, JSON serialization, `--dry-run`, headless auth | Turn-key **Agent Plugin** & **MCP Server** |
| **Tier 4** | **Agent-Capable** | Scriptable or CLI-based with minor interactive gaps | **Clustered MCP Server** with light glue |
| **Tier 3** | **Scriptable** | Utility scripts and subcommands available | **Skill with Code** (deterministic script wrapper) |
| **Tier 2** | **Workflow-Only** | Procedural, algorithmic, or internal library | **Pure Skill** (procedural rules & guidelines) |
| **Tier 1** | **Manual / GUI-Bound** | Dependent on browser interaction or TTY prompts | Modernization required before agent exposure |
